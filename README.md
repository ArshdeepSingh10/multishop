# Boutique + Cake Shop – WhatsApp ordering site (core version)
1. Open `config.js`: set each shop's name and WhatsApp number (digits only, with country code, e.g. 919876543210). Orders stay blocked until a real number is set.
2. Open `data.js`: replace the sample products with real ones. For photos, upload to Cloudinary and paste the image URL into `images: [...]`.
3. Upload all files to a GitHub repo and turn on Settings > Pages. Open `index.html`.
Note: WhatsApp links can only carry text, so product photo links are included in the message. Customers attach their own reference photos in the chat (there is a checkbox for cakes).
